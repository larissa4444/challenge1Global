# 1GLOBAL Challenge - BetterRoaming

End-to-End (E2E) test automation for the **BetterRoaming** website, built using **Playwright** with **TypeScript** and following the **Page Object Model (POM)** pattern.

## 🚀 Technologies
* Playwright
* TypeScript

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/larissa4444/challenge1Global.git](https://github.com/larissa4444/challenge1Global.git)
   cd challenge1Global

1. **Install dependencies:**
   Install playwright: npm install
   Browsers and dependencies: npx playwright install --with-deps
   Run the tests: npm run test
   Run tests with trace view: npx playrwright test  --trace on
   Run Report: npx playwright show-reportA
